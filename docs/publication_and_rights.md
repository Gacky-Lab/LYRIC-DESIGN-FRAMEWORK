# 公開範囲・ライセンス・個人情報に関する注意

- 本ZIPの **GitHub公開用パッケージ**には、方法論・テンプレート・軽量な採点チェック・概要図のみを入れる。
- 以前の内部Excel（17シート）には、未発表の楽曲名・制作優先順位・仮評価・歌詞草稿・画像等が含まれる可能性がある。公開版へ**自動同梱しない**。
- 試聴データの氏名・ID・生の自由記述・録音・連絡先・未許諾の楽曲ファイルを公開しない。
- 生成画像は概要説明のための素材。学術的な事実や仕様の正本ではない。権利・第三者キャラクター等の利用規約を個別に確認する。
- 他者の歌詞・音源、商用音源ライブラリ、認証情報を含めない。
- `LICENSE` を意図的に同梱していない。コードをMIT、文書をCC BYなどにするなら権利範囲を確認して**本人が別途選択**する。現状では第三者への包括的な再利用許諾は付与しない。
- 心理的・生活上の悩みを歌にすることは、医療的・経済的・社会制度上の問題を解決することではない。

**GitHubへPushする前:** ZIP展開後に画像・パス・コミット対象を点検する。必要なら画像を削除し、READMEの参照を調整する。
