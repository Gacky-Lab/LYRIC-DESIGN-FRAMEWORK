# English overview

**LYRIC DESIGN FRAMEWORK** is an independent, design-stage editorial framework for songwriting, developed by Gacky / Gacky-Lab.

It separates four activities: (1) segment creative themes into perspective, emotion, and temporal focus; (2) structure a narrative/emotional arc; (3) evaluate drafts with eight weighted editorial criteria; and (4) test and revise using controlled listening feedback. This is **not** an empirically validated hit-prediction system, nor an end-to-end AI songwriting engine.

The emotion dimension references the valence/arousal model of affect, whereas the perspective and temporal dimensions are the author's editorial choices. The weighted 100-point rubric reflects a creative preference rather than an optimized scientific score.

The repository includes Japanese documentation, JSON templates, a standard-library-only score validator, and an illustrative infographic. Experimental listener data and unpublished songs are intentionally excluded from the public package.
