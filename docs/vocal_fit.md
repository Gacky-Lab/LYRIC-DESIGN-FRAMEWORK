# 歌詞単体の評価と音源上の歌唱適合を分ける

元Excelの `15_歌唱適合` から、別の6軸・100点を採用する。

| 軸 | 重み | チェック |
|---|---:|---|
| 明瞭さ | 25 | 助詞・重要語が聞き取れるか |
| 日本語アクセント | 20 | 不自然な強勢・イントネーションがないか |
| 音節リズム | 15 | モーラ数・休符・フレーズ長が無理なく乗るか |
| サビ記憶 | 20 | 同じ音源条件で一行／旋律が残るか |
| 感情整合 | 15 | 音色・抑揚・編曲と歌詞の感情が矛盾していないか |
| 合成声表現 | 5 | 合成音声特有の響きが作品意図に合うか |
| **合計** | **100** | |

### 原則

- 実際に試聴していない場合は**未採点**。
- Sunoで生成された女性合成風の声は、公式の初音ミク音声ライブラリそのものではない。
- 初音ミク等の純正音声で試す場合は正規の権利・製品環境を用いる。
- **歌詞点と歌唱点を合算して「ヒット確率」に変換しない。**
- A/Bで歌詞のみの違いを測りたい場合はメロディー、声、伴奏、速度、ラウドネス等を揃える。
