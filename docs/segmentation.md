# 3軸の層別：異なる種類の概念を混ぜない

## 目的

歌詞の出発点が、社会状況であっても、失恋であっても、空想上の問いであっても、共通の見方で比較する。

## A｜視点の射程（誰の・何の問題として描くか）

**自己 / 対人 / 社会 / 存在・世界**。

例は汎用の整理上の説明であり、楽曲案ではありません。自己の悩みでも社会環境が背後にあれば、副軸として「社会」を持てる。これらは互いに排他的なカテゴリではない。

## B｜感情状態（心の位置・動き）

**快／不快（valence） × 高覚醒／低覚醒（arousal）**を、直交する2次元として使う。

- 高覚醒は「前向き」と同義ではない。怒り・恐怖にも高覚醒がある。
- 低覚醒は「暗い」と同義ではない。安堵・落ち着きもありうる。
- 感情の時間的軌跡（序盤→サビ→終幕）を複数点として置くことができる。
- 感情の円環モデルは、音楽の好みや歌詞の質を自動判定するものではない。

## C｜時間の焦点

**過去 / 現在 / 未来**。回想・現場・予期のどこに語りの重心があるかを記録する。物語が時間をまたぐなら複数に付ける。

## 運用ルール

- 最初は主軸をひとつずつ選び、副軸がある場合だけ記録。
- 「恋愛」「怒り」「後悔」は異種の概念（題材／感情／時間指向を伴う心理）なので同じ階層に並べない。
- 題材の**発想源**（社会変化・個人体験・日常の情景・想像・抽象的なテーマ）は、この3軸とは別フィールドとして残す。
- 必要なら「語り手」「受け手」「場所」「時代」など他の切り口を追加。3軸だけであらゆる創作を網羅するとは主張しない。

## 根拠と独自性

Russell (1980) の感情の円環モデルは感情状態の捉え方に関連する。**Aの視点分類とCの時間焦点は本プロジェクトの編集上の設計**であり、当該研究から直接導いた尺度ではない。詳細は `research_and_limits.md`。
