# 5つの創作要素と逆算ルート

**順序は固定ではない。** すでに強い一行・旋律・タイトルがある場合、そこから他要素を逆算してよい。

| 要素 | 答える問い | 改稿判断 |
| --- | --- | --- |
| 1. 核となる問い | この曲は何を問い直すか | 説教や結論ありきになっていないか |
| 2. 心の揺れ | 相反する感情や本音はあるか | 心理的矛盾は必須ではなく、ある場合に活かす |
| 3. 具体的な情景 | 誰が、どこで、何を見て、どう動くか | 抽象語だけで進めていないか |
| 4. 独自の一行 | その曲だけの視点の変化はあるか | 常套句の置換になっていないか |
| 5. 感情の変化 | 冒頭と結末で何が違うか | 同じ主張の反復だけになっていないか |

## 他の出発点を認める

- **Melody-first:** 旋律・リズムを先に確定、歌詞の音節と母音を合わせる。
- **Hook-first:** 印象的な一行から問い・情景・結末を逆算。
- **Scene-first:** シーンを細かく描いてから主題を見つける。
- **Abstract/experimental:** 意味の余白・音の面白さを中心に据える。5要素を形式的に埋めない。

## 完成条件（編集判断）

各要素が記述されているかではなく、その曲の狙いに必要な要素が機能しているかで判断する。意図的な抽象性や反復は、採点時に「欠陥」と断定しない。
